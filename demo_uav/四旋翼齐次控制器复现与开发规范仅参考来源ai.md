# 四旋翼齐次控制器复现与开发规范 (基于 ROS 2 + PX4)

## 1. 项目背景与目标
本项目旨在基于 ROS 2 和 PX4 (通过 Micro XRCE-DDS) 复现非线性齐次控制器 (Homogeneous Controller)。核心思想是将工业界现有的线性控制器 (如 PID) 升级为非线性齐次控制器，在不改变硬件的前提下提高控制精度、鲁棒性并加快响应速度，同时抑制线性控制在追求高速响应时产生的“过冲 (peaking effect)”。

## 2. 坐标系定义与数据陷阱 (高优先级注意事项)
* **算法理论坐标系 (Z-Up)：** 论文动力学模型采用 Z 轴垂直向上的坐标系。高度 $Z$ 方程中重力项表达为 $-g$，控制器计算出的正向推力 $u_1$ 对应高度的增加。
* **PX4 系统坐标系 (NED & FRD)：** PX4 飞控底层状态消息 (如 `VehicleOdometry`, `VehicleLocalPosition`) 严格遵守 NED (北东地) 坐标系 (Z 轴垂直向下) 和 FRD (前右下) 机体坐标系。
* **架构要求：** 必须在 ROS 2 控制节点中实现严格的坐标转换模块。订阅到的状态数据必须先从 NED 转换为 Z-Up 再传入控制器计算；控制器输出的推力和扭矩指令必须从 Z-Up 转换回 FRD/NED 后，才能通过 DDS 话题下发给 PX4，严禁直接透传避免控制反向。

## 3. 动力学模型与系统状态方程
系统被解耦为三个独立的线性化子系统，用于后续的齐次化升级。控制算法采用**现代控制理论的状态反馈形式 ($u = Kx$)**，而非经典误差反馈。这解释了为何反馈增益矩阵（如高度环 $K_z = [-35, -14]$）呈现负值，它们在物理效果上等效于经典 PID 的 $k_p=35, k_d=14$。

**关键机械参数：**
* 质量 $m = 1.07$ kg，重力加速度 $g = 9.8$ m/s$^2$
* 惯量 $I_{xx} = 6.85 \times 10^{-3}$, $I_{yy} = 6.62 \times 10^{-3}$, $I_{zz} = 1.29 \times 10^{-2}$ (kg$\cdot$m$^2$)

### 3.1 高度控制子系统 (Z-subsystem)
状态变量 $Z = [z, \dot{z}]^T$，控制输入 $u_1$ (抵消重力后的净推力)。
$$\dot{Z} = A_z Z + B_z u_1, \quad A_z = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}, B_z = \begin{bmatrix} 0 \\ \frac{1}{m} \end{bmatrix}$$

### 3.2 偏航角控制子系统 ($\Psi$-subsystem)
状态变量 $\Psi = [\psi, \dot{\psi}]^T$，控制输入 $u_4$ (偏航扭矩)。
$$\dot{\Psi} = A_\psi \Psi + B_\psi u_4, \quad A_\psi = \begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}, B_\psi = \begin{bmatrix} 0 \\ \frac{1}{I_{zz}} \end{bmatrix}$$

### 3.3 水平位置与姿态子系统 ($\xi$-subsystem)
状态变量 $\xi = (x, y, \dot{x}, \dot{y}, \theta, -\phi, \dot{\theta}, -\dot{\phi})^T$，控制输入 $u_2, u_3$ (俯仰、滚转扭矩)。
$$\dot{\xi} = A_\xi \xi + B \begin{pmatrix} u_2 \\ u_3 \end{pmatrix}$$
$$A_\xi = \begin{bmatrix} 0 & I & 0 & 0 \\ 0 & 0 & gE & 0 \\ 0 & 0 & 0 & I \\ 0 & 0 & 0 & 0 \end{bmatrix}, \quad E = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}, \quad B = \begin{bmatrix} 0 \\ 0 \\ 0 \\ \text{diag}(\frac{1}{I_{yy}}, \frac{1}{I_{xx}}) \end{bmatrix}$$

## 4. 齐次控制器核心算法设计
对于已有的线性控制器 $u_{lin}(x) = K_{lin}x$，通过引入扩张矩阵 $d(s) = e^{s G_d}$ 和规范齐次范数 $\|x\|_d$，可将其升级为非线性齐次控制器：
$$u(x) = K_0 x + \|x\|_d^{1+\mu} K d(-\ln\|x\|_d) x$$
*参数约定*：$K = K_{lin} - K_0$，齐次度 $\mu < 0$ (实现有限时间稳定)。

**工程化饱和处理：**
为避免状态逼近0点时增益趋于无穷大导致物理设备严重颤振 (Chattering)，必须引入饱和函数 $\text{sat}_{a,b}(\|x\|_d)$：
$$u_{a,b}(x) = K_0 x + K d(-\ln \text{sat}_{a,b}(\|x\|_d)) x$$
在单位球外（状态误差大），算法表现为线性 PID 行为；在逼近原点时，按非线性法则放大增益，确保在任何情况下的性能下限均不低于原线性控制器。

## 5. 工程实现与调试要点

### 5.1 控制指令下发层级 (Offboard Control)
* **推荐方案 (级联替换)：** 发布 `vehicle_rates_setpoint` 话题。将 $\xi$ 和 $\Psi$ 齐次子系统作为姿态/角速度发生器，保留 PX4 底层的角速度 PID 环。
* **底层方案 (直接混控)：** 若需完全验证论文扭矩输出，需直接发布 `actuator_motors` 话题。这就要求在 ROS 2 节点中自定义实现控制分配算法 (Mixer)，将物理扭矩转化为 0-1 的电机 PWM 归一化指令。

### 5.2 重力前馈补偿与油门缩放
高度控制器算出的 $u_1$ 不含重力。在下发推力指令时，必须读取无人机的实际悬停油门参数 (对应 PX4 参数 `MPC_THR_HOVER`)，计算最终归一化推力：
`Thrust_cmd = Normalize(u_1) + Hover_Thrust`，否则切入 Offboard 模式瞬间会发生剧烈掉高。

### 5.3 闭环调试与防颤振监控
由于齐次算法非线性项的高频特性，需开发一套基于 Qt 和 C++ 的多串口/网络上位机监控软件。
* **功能需求：** 实时解析 ROS 2 节点或 MAVLink 传回的控制输出量 ($u_1 \dots u_4$)、无人机轨迹速度以及当前的齐次范数值 $\|x\|_d$。
* **调试目标：** 通过上位机动态绘制数据曲线，观察 0 点附近的信号突变率，以此来精确标定饱和函数 $\text{sat}_{a,b}(\|x\|_d)$ 的边界阈值 $b$。

### 5.4 版本与依赖管理
开发期间若涉及 PX4 固件端或 MAVLink 消息头文件（如自定义控制量消息体）的修改，应利用 Git 子模块隔离，并将相关调试代码保存在带日期的开发分支（如 `my_qgc_mods_archive`）中进行留存管理，避免与主分支环境冲突。
