## 1. 架构与核心函数

### 1.1 数学基础

齐次控制通过引入**膨胀对称性（dilation symmetry）**来推广线性控制。
对于以 `Gd` 为生成元的膨胀群 `d(s) = expm(s·Gd)`，齐次范数
`nx = hnorm(x, Gd, P)` 满足：

```
||d(s)·x||_h = e^s · ||x||_h
```

核心思想：将线性控制器 `u = K·x` 升级为齐次控制器：

```
u = K0·x + nx^(1+μ) · (K-K0) · d(-ln(nx))·x
```

其中：
- `K0`：齐次化反馈增益（线性部分）
- `K-K0`：非线性增益
- `μ`：齐次度（μ < 0 → 有限时间收敛，μ > 0 → 近似固定时间收敛）
- `nx`：典范齐次范数

### 1.3 核心算法：`lpc2hpc(A, B, K)`

```
输入:   A (n×n), B (n×m), K (m×n)  — A+BK 必须是 Hurwitz 矩阵
输出:   K0, G0, P, μ_min, μ_max

步骤1: 块分解 [T, nt] = block_con(A, B)
        将 {A,B} 变换为典范可控型

步骤2: 计算齐次化增益 K0
        K0 = -B0'·(B0·B0')⁻¹·A_last_row
        使得 A0 = A+B·K0 在最后一块行上幂零

步骤3: 计算膨胀生成元 G0
        vG0 = [k-1 重复 n₁ 次, ..., 0 重复 nₖ 次]
        G0 = -T⁻¹·diag(vG0)·T
        Gd = I + μ·G0

步骤4: 计算形状矩阵 P
        求解 Lyapunov 方程: (A+BK)'P + P(A+BK) = -2I
        通过 Kronecker 积: kron(I, Acl') + kron(Acl', I)

步骤5: 计算 μ 的容许范围
        计算 sqrt(P)·G0·sqrt(P)⁻¹ + sqrt(P)⁻¹·G0'·sqrt(P) 的特征值 λ
        → [μ_min, μ_max]
```

### 1.4 核心算法：`lpic2hpic(A, B, K, Ki)`

在 `lpc2hpc` 的基础上额外执行：
- 求解含积分增益 `Ki` 的修正 Lyapunov 方程得到 `P`
- 通过最小二乘法计算 `P2`：`Ki'·P2 = -B'·P` 和 `P2·Ki = -P·B`
- 重构积分增益：`Ki_new = -P2⁻¹·B'·P`
- μ 容许范围更窄：μ_min ≥ -0.5

> **注意**：在 MATLAB 源码 `lpic2hpic.m` 第 123-126 行中，Lyapunov 方程的 `Q1` 矩阵
> 使用的是原始系统矩阵 `A` 而非闭环矩阵 `At = A+BK`。Python 移植已匹配此行为。

### 1.5 齐次范数计算：`hnorm(x, Gd, P)`

二分法求解 `c` 使得：

```
y = expm(-c·Gd)·x    满足    y'·P·y = 1
```

则 `nx = exp(c)`。算法先沿负方向倍增 `a` 和正方向倍增 `b` 来确定包含解的区间，
再通过二分法以 1e-6 的精度收敛。最大迭代次数 20 次。

## 2. Demo 1: lpc2hpc

**文件：** `demo_lpc2hpc.py`
**系统：** 旋转倒立摆 (QUBE-Servo 2)，n=4 状态，m=1 输入

### 参数配置

| 参数 | 值 | 含义 |
|------|-----|------|
| A | 4×4 | 倒立摆系统（有特征值 +13.58 — 开环不稳定） |
| B | 4×1 | 执行器输入矩阵 |
| K_lin | [2, -35, 1.5, -3] | 厂商提供的线性反馈增益 |
| μ | **-1.0** | 负齐次度 → hn⁰ = 1（无放大） |
| α, β | 0.1, 1.0 | 齐次范数饱和界 |
| 离散化方法 | **ZOH** | 零阶保持器（数值稳定） |
| 控制饱和 | **±10V** | QUBE-Servo 2 硬件限幅 |
| T_max | 3 s | 仿真时长 |
| h | 0.001 s | 采样周期 |

### 控制律

```
u = K0·x + nx^(1+μ) · K · expm(-ln(nx)·Gd) · x
```

当 μ=-1 时：`nx^(1+μ) = nx^0 = 1` → 无幅值放大，齐次投影仅改变方向（限制在单位球面上），不改变大小。

### 运行结果

```
||x(3s)|| = 0.000587
```

平滑快速收敛到零，4 个状态均无超调地衰减。

### 运行方式

```bash
python3 hcs_toolbox_py/demo_lpc2hpc.py
```

## 3. Demo 2: lpic2hpic

**文件：** `demo_lpic2hpic.py`
**系统：** 同上倒立摆，增加积分作用 + 常值扰动，忠实复现 MATLAB 原版

### 参数配置

| 参数 | 值 | 含义 |
|------|-----|------|
| K_lin | [2, -35, 1.5, -3] | 线性比例增益 |
| K_lin_int | [0.5, -26.66, 1.26, -2.73] | 线性积分增益 |
| μ | **+0.16** | 正齐次度 → hn^1.16 ≈ 23× 放大 |
| α, β | 0.001, 1000 | 极宽界（几乎无约束） |
| 离散化方法 | **显式 Euler** | 简单但稳定性差 |
| 控制饱和 | **无** | 不真实 — 控制量可任意大 |
| T_max | 4 s | 仿真时长 |
| p | 1.0 | 常值匹配扰动（测试积分作用） |

### 控制律

```
u = uh + v,    dv/dt = ui
uh = K0·x + nx^(1+μ) · K · d(-ln(nx))·x     (比例分量)
ui = nx^(1+2μ) · Ki_new · d(-ln(nx))·x       (积分分量)
```

### 运行结果

```
||x(4s)|| = 0.913
```

**瞬态过程有明显振荡** — 状态范数峰值达到约 28 后才开始收敛。
详见[第 6 节](#6-demo_lpic2hpic-振荡原因分析)的根因分析。

### 运行方式

```bash
python3 hcs_toolbox_py/demo_lpic2hpic.py
```

## 4. Demo 3: lpc_hpc_distance_square

**文件：** `demo_lpc_hpc_distance_square.py`
**系统：** 两个双积分器智能体（二维平面运动），各 n=4 状态，m=2 输入

### 场景描述

```
智能体1（目标/领航者）:  u1 = -[I I]·x1 + [sin(t); cos(t)]
                        → 跟随正弦参考轨迹

智能体2（追捕者）:       u2 = nx_sat^(1+ν) · k_lin · expm(Gd·(1-ln(nx_sat))) · e
                        → HPC 跟踪，保持编队偏移 d
                        e = x2 - x1 - d (跟踪误差)
```

### 编队切换机制

在目标周围半径为 1 的圆上设置 4 个编队点：

```
d_i = -[cos(2πi/4); sin(2πi/4)],  i = 0,1,2,3
```

**切换规则：** 当 `min_i ||x2-x1-d_i|| + tol < ||x2-x1-d_当前||` 时，切换到更近的编队点，
并用自适应线性增益重新设计 HPC 控制器。

### 自适应线性增益

```
a = max(-m · e_vx / e_x, 1)     → λ = diag([a, b])
b = max(-m · e_vy / e_y, 1)
k2 = -2λ,   k1 = λ·(k2+λ)/m
k_lin = [k1, k2]                → 通过 lpc2hpc() 升级为 HPC
```

切换后，最小值限幅从 1 提升到 4（更保守）。

### HPC 公式（专用形式）

```
nx = hnorm(e, Gd, P)
nx_sat = clamp(nx, 0.1, 1.0)     ← 有界齐次范数
u2 = nx_sat^(1+ν) · k_lin · expm(Gd·(1 - ln(nx_sat))) · e
```

> **注意：** 这是专用形式 — `lpc2hpc()` 虽然计算了 `K0`，但在控制律中**并未使用**。
> 直接使用完整的 `k_lin` 增益，且膨胀指数含 `+1` 偏移：`Gd·(1-ln(nx_sat))` 而非标准的 `-Gd·ln(nx)`。

### 运行结果

```
初始 ν = -1.0 (有限时间收敛)
最终 ||e|| = 0.0108 (30s 后)
```

生成 6 张图：X/Y 位置时域图、2D 轨迹图、控制输入图、误差分量图、误差范数图。

### 运行方式

```bash
python3 hcs_toolbox_py/demo_lpc_hpc_distance_square.py
```

## 6. demo_lpic2hpic 振荡原因分析

### 因果链

```
μ = +0.16 (正齐次度)
  ↓
初始状态 [1,1,0,0] 的 hn ≈ 14.9 (大角度: 摆杆 57° + 旋臂 57°)
  ↓
hn^(1+μ) = 14.9^1.16 ≈ 23× 非线性放大
hn^(1+2μ) = 14.9^1.32 ≈ 35× 非线性放大
  ↓
初始比例控制: u ≈ -49  (线性 PI 为: u ≈ -33)
初始积分速率: ui ≈ -59
  ↓
系统特性: A 有特征值 +13.58 (强不稳定)
状态导数: ||dx/dt|| ≈ 2057 (t=0 时)
  ↓
显式 Euler (h=0.001): 每步状态变化约 2.0 (初始范数的 140%)
无饱和限制: 控制量达 -49 → 角加速度约 2500 rad/s²
  ↓
状态范数爆炸: 1.4 → 28 (仅 20ms 内)
然后随积分累积对抗扰动 p=1 缓慢收敛
  ↓
振荡: 激进的齐次增益与系统固有不稳定性之间的大幅拉锯
```

### 各因素贡献表

| 因素 | 贡献程度 |
|------|---------|
| μ = +0.16 (正齐次度) | **首要原因** — 23× 非线性放大 |
| 无控制饱和 | 允许不切实际的大控制量 (-49 vs. 硬件限幅 ±10V) |
| 显式 Euler 离散化 | 对刚性系统稳定性差于 ZOH |
| α/β 界过宽 | 齐次范数几乎无约束 |
| 被控对象不稳定 | A 的特征值 +13.58 放大任何控制误差 |

### demo_lpc2hpc 为何平滑

```
μ = -1.0 → hn^(1+μ) = hn^0 = 1  (无放大)
ZOH 离散化                       (稳定积分)
±10V 饱和                        (真实硬件限幅)
α=0.1, β=1.0                     (紧致约束界)
```

### 优化策略 (Demo 4)

1. **负齐次度** (在容许范围内)：`hn^(1+μ) < 1` 当 `hn > 1` → 在远离原点处**衰减**控制
2. **ZOH 离散化**：消除 Euler 积分的数值误差
3. **控制饱和**：将控制限制在物理可实现范围内
4. **紧致 α, β 界**：防止齐次范数达到极值

## 8. 参数调优指南

### 齐次度 μ

| μ 范围 | 行为 | 适用场景 |
|--------|------|---------|
| μ < 0 | 有限时间收敛 | 快速镇定、扰动抑制 |
| μ = -1 | 无放大 (hn⁰ = 1) | 默认安全选择，类似滑模控制 |
| μ > 0 | 近似固定时间收敛 | 固定调节时间，不依赖初值 |
| μ = μ_min | 容许最负值 | 最强有限时间收敛 |

### 饱和界 α, β

| μ 符号 | 推荐 α | 推荐 β | 理由 |
|--------|--------|--------|------|
| μ < 0 | 0.1 | 1.0 | α 防原点奇异；β 防远处过度衰减 |
| μ > 0 | 1.0 | 10–100 | α 保原点附近线性；β 防远处过度放大 |

### 控制饱和

始终加入与实际执行器限幅一致的饱和。QUBE-Servo 2 电机限幅为 ±10V。
不添加饱和的风险：
- 负 μ：远处控制被衰减 → 可能无法镇定系统
- 正 μ：远处控制被放大 → 超调/振荡
